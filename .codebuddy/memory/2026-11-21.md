## 修复"图纸设置"窗体功能报错
- 用户反馈：窗体能打开，但点"应用"/切换图纸等操作出错（未给具体错误文字）。审查发现多重缺陷并一并修复（`Form/FormSheetSettings.vb`）：

  2. **宽高溢出**：`LoadCurrentSheetInfoToControls` 里 `numericUpDownSheetWidth.Value = Width*10` 若超 Maximum(10000) 抛异常 → 先 `Maximum = Math.Max(Maximum, value)` 再赋值。
  3. **无异常保护**：Load、3 个切换按钮、Apply 全部无 Try/Catch，API 异常直接冒泡 → 全部加 Try/Catch + MessageBox 显示错误（便于用户反馈具体错误）。

  5. 顺序：先设 Size 再设 Orientation（避免横向 A3 被按纵向裁切）。
- **编译错误修复**：用户 IDE 新加了标题栏位置预览 `pictureBoxOrientationPreview.Image = GLTool.Resources.titleblock_BR`（Designer.vb:255），`GLTool` 被解析成项目字符串常量 → BC30456 `'Resources' is not a member of 'String'`。改为 `My.Resources.titleblock_BR`。教训：本项目 `GLTool` 是字符串常量名，资源引用必须写 `My.Resources.xxx`。
