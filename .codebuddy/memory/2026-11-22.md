## FormSheetSettings：载入时读取图纸标题栏实际位置
- 需求：载入窗口时应读取当前图纸的尺寸、方向、标题栏参数，而不是用默认（尺寸/方向/标题栏名称原本已在 `LoadCurrentSheetInfoToControlsCore` 读取；缺的是**标题栏所在角落**一直用设计器默认右下）。
- 新增 `GetTitleBlockLocationFromSheet(sheet)`：取 `sheet.TitleBlock.RangeBox` 的中心点（(Min+Max)/2），与 `sheet.Width/2`、`sheet.Height/2` 比较（Inventor 图纸原点左下角，X 越大越右、Y 越大越上）判断四角，异常兜底右下。`SelectTitleBlockLocationRadio(location)` 选中对应角落 radio。
- 在 `LoadCurrentSheetInfoToControlsCore` 标题栏列表加载后调用 `SelectTitleBlockLocationRadio(GetTitleBlockLocationFromSheet(oActiveSheet))`，使预览图/位置随图纸实际值刷新。
- 参考：`Module/IdwBalloon.vb:867` 用过 `TitleBlock.RangeBox.MinPoint/MaxPoint`（确认 API 可用）。
- 编译通过、lint 0。**未部署**。

## FormSheetSettings：方向默认勾选按图纸实际方向
- 需求：载入时方向要读取当前图纸真实方向并默认勾选，不能图纸竖向却默认勾横向；所有值都应是图纸当前值，避免误点"应用"改动图纸。
- 根因：原用 `oActiveSheet.Orientation` 枚举判断，某些情况（自定义尺寸/该互操作版本）不可靠。
- 修复（`LoadCurrentSheetInfoToControlsCore`）：改为**按宽高判断**——`Width < Height` 为竖向；仅宽高相等（正方图纸）才退回枚举判断。并显式设两个 radio（Portrait/Landscape 互斥，明确赋值避免残留）。加载期 `m_loadingSheetInfo=True` 抑制 CheckedChanged 回填。
- 编译通过、lint 0。**未部署**。
