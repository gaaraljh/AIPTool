## VS 调试 .NET 8 comhost 的兼容性问题（结论）
- 用户实测：Ctrl+F5（不调试）Inventor + AIPTool 完全正常；但「调试 > 附加到进程」选"托管 .NET Core"附加到 Inventor.exe 后，Inventor 崩溃退出码 **3221225477 (0xc0000005) Access violation**。
- 结论：.NET 8 的 COM 宿主（comhost.dll）嵌入原生 Inventor.exe 时，**VS 调试器（F5 与附加到进程）都不兼容**——F5 退出码 1，附加到进程 0xc0000005。两者均**非 AIPTool 业务代码 bug**（不调试时正常）。根因是 VS 的 .NET Core 调试器对"原生宿主延迟加载 CLR 的 COM 组件"支持缺陷，叠加 Autodesk 不支持 .NET 8 插件。
- 对策：放弃用 VS 调试 AIPTool；日常验证用 Ctrl+F5，排障靠 `%TEMP%\AIPTool_debug.log`（已带 PID 头 + 全回调 Try/Catch + 未处理异常记录）。如需定位具体功能崩溃，在可疑回调里加 DbgLog 进入/离开标记，看日志最后停在哪。
- 已把该事实记入 MEMORY.md「固定坑」第 7 条。
