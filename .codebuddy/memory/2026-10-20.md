# 2026-10-20 工作记录

## CreatNewDrawingDocumentSub 保存逻辑修复（Module\IdwModule.vb）
- 问题：新建文件保存后"重复保存 / 反复提示是否覆盖"。
- 根因：①覆盖分支 `SaveAs(...,False)` 后又 `Save2()` 重复保存；②新文件(Else)分支用 `Save2()` 对无名新建文档会弹原生另存为且不写到目标路径，导致目标永不生成、下次又提示覆盖；③顶部"打开已有IDW"选是后缺 Exit Sub 会继续新建并覆盖；④"另存为其他名"分支用 Save2 忽略所选名。
- 修复：所有保存统一为单次 `SaveAs(目标, False)`（删除全部 Save2）；新文件直接 SaveAs 到目标；打开已有IDW后 Exit Sub。✅ 经验：Inventor 新建无名文档要用 SaveAs(全路径,False) 落盘，不能用 Save2()（会弹原生对话框）。

## "文件保存已取消" 假提示修复（Module\IdwModule.vb）
- 问题：保存后弹"文件保存已取消"，但文件实际已正常保存。
- 根因：两段 Else 分支里 `If IsFileExists(...) = False Then MsgBox("文件保存已取消")` 原用于检测"用户取消原生另存为对话框"，但改用 SaveAs 后不再弹框、判断已无意义；且旧代码在 IDW 分支误查了 DWG 文件名（IDW 已存、DWG 未生成 → 误判取消）。SaveAs 失败会直接抛异常，不会走到该判断。
- 修复：两个分支该判断条件置为 `If False`（加注释），MsgBox 不再触发。
- 注意：该 MsgBox 行含全角左引号 `“`（U+201C），replace 直接匹配整行易失败；涉及此行的精确替换应用 ASCII 上下文（如只匹配 `If IsFileExists(...) = False Then` 这一行）来避开引号，或整段注释掉。
