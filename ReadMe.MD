# AIPTool是什么?
AIPTool是Autodesk Inventor 插件，基于原Leaky114开源的XHTool插件（现已闭源）修改使用。

# AIPTool支持哪些版本?
目前测试支持到Inventor2016-2025版。 

# AIPTool有哪些功能?
- iProperty自动填写
- 部件内修改零部件文件名
- 检查是否存在零件对应工程图
- 双零部件对齐原始坐标
- 图号自动生成
- 导出平面BOM
- 移动指定文件
- 查找缺失文件
- 清理旧版文件
- 设置ERP编码
- 导入ERP编码(Excel文件支持)
- 查询ERP编码(Excel文件支持)
- 导入ERP编码到BOM表(Excel文件支持)
- 零部件随机颜色
- 标准件可见性
- 文件的只读属性
- 工程图快速打印
- 批量打印工程图
- 工程图另存为dwg
- 工程图另存为pdf
- 零部件另存为stp
- 工程图文件批量另存
- 工程图尺寸圆整
- 工程图尺寸添加直径
- 工程图尺寸居中
- 技术要求的管理
- 检查工程图零件序号完整性
- 新建工程图零件序号
- 环形自动重建序号
- 根据模板文件替换工程图标题栏和图框
- 钣金厚度检查
- 零件克隆装配
- 自动创建工程图
- 自动创建钣金展开图
- 多文档切换
- 驱动测量
- 动态尺寸
- 展开图隐藏螺纹、导出dxf文件添加材质、标记孔径上限
- 资源管理器
- 移动文件
- 清净世界
- 部件选择多文件打开
